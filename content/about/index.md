I’m Mehdi Hasanzadeh Samadi—usually Farokh—a DevOps engineer based in Tehran. I work on the platforms, automation, and operational practices that help software run reliably in production.

My professional path includes DevOps engineering at **Irancell Labs**, **Asiatech**, and **Atieh Dadeh Pardaz**, along with earlier work in Linux systems administration and solution architecture.

## What I work with

My day-to-day toolkit centers on Linux, Kubernetes, Terraform, Helm, Jenkins, and shell scripting. For observability and operations, I work with systems including Prometheus and Elasticsearch.

I’m interested in the full operational lifecycle: provisioning infrastructure, automating repeatable work, making deployments safer, observing real behavior, and improving systems using what production teaches us.

## How I approach systems

- Automate repetitive work without hiding important decisions
- Prefer observable systems over operational guesswork
- Make dangerous procedures explicit, validated, and reversible
- Keep infrastructure understandable as it grows
- Share tools and lessons that can save someone else time

One example is my interactive Bash utility for [safer Kubernetes node upgrades](https://www.linkedin.com/pulse/interactive-bash-script-safe-custom-kubernetes-node-mehdi-frzzf). It detects node roles, guides component selection, validates requested versions, and handles the differing needs of worker and control-plane nodes.
